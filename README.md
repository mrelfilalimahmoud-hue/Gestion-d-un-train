# 🚂 Train Management System

## 📝 About The Project
This project is a terminal-based Train Management System developed in **C**. It focuses on the practical application of advanced data structures and algorithmic optimization to manage railway logistics, passenger reservations, and train scheduling.

## ✨ Key Features
- **Wagon & Train Management:** Efficiently managed using linked lists and dynamic structures.
- **Passenger Reservations:** Booking, tracking, and cancellation system.
- **Route Optimization:** Algorithmic approach to manage schedules and train paths.
- **Memory Optimization:** Strict dynamic memory allocation and pointer manipulation to prevent memory leaks.

## 🛠️ Tech Stack
- **Language:** C
- **Core Concepts:** Data Structures, Algorithms, Pointer Manipulation, Memory Management.
